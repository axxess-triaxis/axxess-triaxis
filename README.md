## AXXESS by Triaxis

[**AXXESS TRIaxis**](https://github.com/axxess-triaxis/AXXESSTRIAXIS) is an enterprise AI operating platform for regulated organizations. It combines AI orchestration, policy enforcement, workflow automation, enterprise integrations, human-in-the-loop review and compliance-oriented controls in one platform.

Built with Next.js, TypeScript, Supabase and Capacitor, for web, iOS and Android.
